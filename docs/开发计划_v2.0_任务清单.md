## 0. 来源与基线

v2.0 条目来自四类输入：

1. **v1.0 明确推迟的需求**：P5.3 `LocalRuleNluEngine`、P5.6 `VoicePanel/AiTextSheet/AiViewModel/AiAssistantImpl`（已被 `AssistantScreen` 等价覆盖，转为「深化」而非「补齐」）。
2. **发布说明已知限制**：Android 14+ 全屏提醒降级、位置提醒（`addProximityAlert`）受省电策略影响、本地语音识别为系统框架 best-effort。
3. **代码/设计遗留问题**（封板审计中刻意不入 v1.0、留待 v2.0 的低风险增强）：
   - 散落的 `Log.w/e`（AudioCapture / AudioPlayer / RecycleBinPurgeReceiver），无统一日志基础设施与在屏查看/导出能力；
   - `AppDatabase.exportSchema = false`，Room 迁移缺少 schema 产物，长期迁移风险；
   - 仅手动 JSON 备份，无自动备份 / 备份版本化；
   - 无仪器化测试（`androidTest`），纯 JVM 单测无法覆盖 Compose/系统交互。
4. **产品体验缺口**（竞品对标 / 用户访谈常见诉求）：桌面小组件、动态快捷方式、键盘快捷键、ICS 日历导入导出、自动备份、离线 ML ASR。

> **工程纪律（沿用 v1.0 红线）**：中文全抽离 `strings.xml`、Room 显式 `Migration` 禁 `fallbackToDestructiveMigration`、**不引入新依赖**（复用 OkHttp/DataStore/系统框架/WorkManager 若已可用）、每次完成即按功能拆 `git commit`、提交前缀 `[fix]/[feature]/[config]/[test]/[docs]/[refactor]/[chore]`。

## v2.0 封板（2026-07-24）

Phase 1–6（V2.1–V2.21，共 21 项）**全部交付**。封板前做了三项收尾工程：

### 1. 全量 lint 门禁复跑（0 errors 通过）
- 门禁：`abortOnError=true` + `checkReleaseBuilds=true`（`warningsAsErrors=false` 保留告警可见性）。
- 修复 8 个 lint error：
  - `ShortcutHelper`：动态快捷方式 `ShortcutInfo.Builder` 系列需 API 25，`build()` 加 `@TargetApi(N_MR1)`（调用方已有 `SDK_INT` 守卫）。
  - `TodayWidgetService`：`RemoteViews` 不支持 `CheckBox` → 布局改 `ImageView` + 系统 drawable（`checkbox_on/off_background`）表示勾选态。
  - `StatsViewModel`：`String.format` 补 `Locale.ROOT`（修复土耳其语等 locale 下默认 locale 隐患）。
  - `TodayScreen`：`mutableStateOf(0)` → `mutableIntStateOf`（消除自动装箱状态分配）。
  - `widget_today_item.xml`：补 `paddingEnd` 修正 RTL 对称。
  - 清理 47 个死字符串（`UnusedResources`）+ 1 个未用色值 `seed`，降低 warning 数。

### 2. 深度代码审计与修复（高 → 中风险）
- **[高危] 泄露**：`AssistantViewModel.onCleared` 中 `transport.disconnect()` 经 `viewModelScope.launch` 启动，但 `super.onCleared()` 会取消 `viewModelScope` 致其永不执行 → WebSocket / AudioTrack / 内部作用域泄露，且再次进入助手 `connect()` 因 `connected==true` 直接 return。改为独立 `CoroutineScope(IO)` 执行。
- **[中危] 数据一致性**：`CompleteTaskUseCase` 跨表写（实例完成 + CompletionLog + Task 终态）包进 `AppDatabase.withTransaction` 原子事务（满足 AGENT.md 跨表写事务要求）。
- **[中危] 交互正确性**：今日键盘监听闭包捕获过期 `state` → 改用 `rememberUpdatedState` 读取最新列表，避免误操作；`focusedIndex` 改 `rememberSaveable` 跨旋转保留。
- **[中危] 主线程**：`GeofenceScheduler` 去除 `runBlocking(Dispatchers.IO)` 阻塞，改用内部协程作用域 + `withContext(IO)`。
