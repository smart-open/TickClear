## 3. 视觉美化专项（已落地）

### 3.1 根因
用户反馈"画的动物/物件太丑陋、没有动画"。精读后发现：
- 动物/物件多由 `drawCircle`/`drawOval`/`drawPath` **平涂单色**构成，无光影 → 扁平、无体积。
- 部分工具（宠物/木鱼/烟花）**已有动画与粒子**，但视觉仍单薄。
- 缺统一"立体绘制"能力，导致每工具各画各的、质量参差。

### 3.2 解决方案：`IllustrationKit.kt`（新建共享库）
零新依赖、纯 `Canvas` 扩展函数，全部工具可复用：
- `Color.lighten/darken` — 本地安全派生明暗。
- `drawContactShadow` — 径向渐变伪造软投影（不依赖 blur 后处理）。
- `fillSphere` / `fillOvoid` / `fillRoundRect3D` / `fillPath3D` — 径向渐变（高光→基色→暗部）模拟受光体积 + 背光侧边缘光。
- `drawGloss` — 表面光泽高光（湿润/反光质感）。
- `isMotionReduced(context)` — 读系统 `ANIMATOR_DURATION_SCALE`，尊重无障碍"减少动态"。

### 3.3 示范升级（已编译通过）
- **`PetScreen`**：鱼/狗/猪/猫 全部改用受光球面+椭球+路径，加接触投影与光泽；眨眼/摆尾/扑逗动画保留；接入 `reduced-motion` 闸门冻结 idle 动画。
- **`SimWoodFishScreen`**：木鱼主体改受光圆角矩形（木纹暖棕渐变）+ 圆头鼓包 + 雕刻开口内壁暗影 + 顶部高光 + 接触投影；敲击时横向压扁挤压动画。

## 4. 性能 / 完整性 / 可用性 共性问题

1. **列表性能**：`ToolsScreen` 已改为 `LazyColumn`（旧版一次性组合 56 卡首帧卡顿），`favoriteSet` 转 `Set` 做 O(1) 判重 — 良好实践，其余长列表工具应沿用。
2. **帧循环**：模拟类用 `withFrameMillis` + `dt` 夹紧（≤0.05s）避免卡顿后大跳 — 规范，新动画务必沿用。
3. **状态提升**：`MaterialTheme.colorScheme` 须在组合作用域取值后传入 `DrawScope`（已多处正确实践），禁止在 lambda 内调用 `@Composable` getter。
4. **Bitmap 回收**：图片类（马赛克/去水印/压缩/灰度）务必 `recycle()` 原图，否则连开 OOM（见 AGENT.md）。
5. **无障碍**：本次为宠物接入 `reduced-motion`；其余动画工具应统一接入 `isMotionReduced`。
