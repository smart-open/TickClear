## 一、§13 开放问题决策落地（本轮明确）

- [x] **V2.63 · Q2 音效用开源素材** — 决策：使用开源授权音效素材，纳入 `res/raw`，无新增依赖。实现：生成/引入开源许可短音（MIT/CC0），高优先级提醒播放自带音而非仅系统默认声。
- [x] **V2.64 · Q3 位置提醒用高德（决策落档，不接 SDK）** — 决策：位置提醒维持系统定位（FusedLocationProvider/GeofenceScheduler，零 GMS、零新依赖）；高德记为未来地图选点/逆地理编码选型。**v2.6 不引入 SDK**，仅将决策写入文档。
- [x] **V2.65 · Q8 语音历史（默认关闭）** — 决策：语音历史功能默认关闭。实现：`voiceHistoryEnabled` 默认 false；新增语音历史存储（指令文本 + 时间），设置中可开启；开启时记录助手会话/指令。
- [x] **V2.66 · Q9 常驻语音唤醒 MVP** — 决策：v2.6 实现常驻语音唤醒 MVP。实现：前台服务 `WakeWordService`（`foregroundServiceType=microphone`）复用 `WakeWordManager`（系统 `SpeechRecognizer` 持续识别，零新依赖）做**关键词 spotting**，命中设置中的唤醒词（默认「小清」）即经 `WakeWordBus` 跳转助手页自动收音；设置开关默认关，开/关联动启停前台服务。**局限**：依赖系统识别服务、并非端侧神经网络模型；真正端侧离线唤醒词需 ML 运行时（破红线，记为后续 V2.72/V2.75）。

## 二、产品规划功能缺口（LATER v1.2+，转入 v2.6 开发）

> 🔶 以下为零新依赖可独立实现项（除标注外）；需模型/外部 SDK 的项已注明。

- [x] **V2.67 · 任务标签 / 分类** — 任务可打标签，按标签筛选。实现：`task` 表新增 `tags` CSV 列（`MIGRATION_6_7`，DB v6→7，导出 `7.json`）；`Task` 领域模型加 `tags: List<String>`，仓库映射边界 CSV↔List（`TaskMappers.toTagList/toTagCsv`）；编辑表单加标签输入框 + 已有标签快捷 chips；任务列表顶部标签筛选条（多选并集，`TasksViewModel.selectedTags`），任务行显示 `#标签`；备份序列化携带 `tags`（向后兼容，未升 SCHEMA_VERSION）。零新依赖、中文全抽离、显式迁移。
- [x] **V2.68 · 更多主题皮肤** — 在现有主题切换基础上扩展多套配色皮肤。实现：新增 `ThemeSkin` 枚举（BLUE/GREEN/PURPLE/ORANGE/ROSE/TEAL），与 `ThemeMode`（浅/深/动态）正交解耦——最终配色 = 模式 × 皮肤；`Color.kt` 以种子色经 HSL 派生各皮肤明/暗 `ColorScheme`（`skinScheme(skin,dark)`、`skinPreviewColor` 供设置页预览），BLUE 复用原 `LightColorScheme/DarkColorScheme` 保证零回归；`TickClearTheme(mode,skin)`、`SettingsRepository.themeSkin`（`theme_skin` DataStore 键，默认 BLUE）、`SettingsViewModel/RootViewModel` 透传；设置页外观区新增皮肤选择行（带主色圆点预览的 `FilterChip`），关于页 `about_current_theme` 回显「模式 · 皮肤」。零新依赖、中文全抽离、无 DB 迁移。
- [x] **V2.69 · 习惯养成模式** — 周期性习惯任务 + 连续打卡 streak 展示。实现：新增 `habit` 表（定义）与 `habit_checkin` 表（每日打卡，复合主键 habitId+dateLocal），`MIGRATION_7_8`（DB v7→8，导出 `8.json`）；`HabitEntity/HabitCheckInEntity` + `HabitDao/HabitCheckInDao`；`HabitRepository`（`observeHabits/observeCheckinDates/checkIn/uncheck/create/update/delete`）；`domain/util/HabitDates`（纯函数 `todayLocal/computeStreak/isHabitDueToday`，用 Calendar 兼容低 minSdk）；`HabitsViewModel` 用 `flatMapLatest+combine` 叠加「今日已打卡 + 连续天数」；`HabitsScreen` 列表卡片 + 打卡/取消按钮 + 删除确认 + 新建习惯对话框（名称/emoji/星期选择）；导航新增 `Routes.HABITS` 顶级目的地（底部栏/导航轨「习惯」Star 图标）。零新依赖、中文全抽离、显式迁移。
