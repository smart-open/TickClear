## 一、§13 开放问题决策落地（本轮明确）

- [x] **V2.63 · Q2 音效用开源素材** — 决策：使用开源授权音效素材，纳入 `res/raw`，无新增依赖。实现：生成/引入开源许可短音（MIT/CC0），高优先级提醒播放自带音而非仅系统默认声。
- [x] **V2.64 · Q3 位置提醒用高德（决策落档，不接 SDK）** — 决策：位置提醒维持系统定位（FusedLocationProvider/GeofenceScheduler，零 GMS、零新依赖）；高德记为未来地图选点/逆地理编码选型。**v2.6 不引入 SDK**，仅将决策写入文档。
- [x] **V2.65 · Q8 语音历史（默认关闭）** — 决策：语音历史功能默认关闭。实现：`voiceHistoryEnabled` 默认 false；新增语音历史存储（指令文本 + 时间），设置中可开启；开启时记录助手会话/指令。
- [x] **V2.66 · Q9 常驻语音唤醒 MVP** — 决策：v2.6 实现常驻语音唤醒 MVP。实现：前台服务 `WakeWordService`（`foregroundServiceType=microphone`）复用 `WakeWordManager`（系统 `SpeechRecognizer` 持续识别，零新依赖）做**关键词 spotting**，命中设置中的唤醒词（默认「小清」）即经 `WakeWordBus` 跳转助手页自动收音；设置开关默认关，开/关联动启停前台服务。**局限**：依赖系统识别服务、并非端侧神经网络模型；真正端侧离线唤醒词需 ML 运行时（破红线，记为后续 V2.72/V2.75）。
