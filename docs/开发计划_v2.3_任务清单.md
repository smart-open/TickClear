## 二、任务清单（Phase 8）

### V2.30 多档稍后提醒时长
✅ 新增 `snoozeDefaultMin` 设置（DataStore 键 `snooze_default_min`，受 `ReminderPrefs.SNOOZE_OPTIONS = {5,15,30}` 约束）。
✅ `SettingsRepository`/`SettingsViewModel` 暴露状态与 setter；`ReminderPrefs.normalizeSnoozeMin` 做归一化（JVM 可测）。
✅ 设置页以分段选择（FilterChip）呈现 5/15/30 分钟。
✅ `ReminderReceiver` 通知动作、`FullScreenAlertActivity` 全屏「稍后」均改用该设置，默认 15 分钟。
✅ 单测 `ReminderPrefsTest` 覆盖归一化与默认值。

### V2.31 提醒音效开关
✅ 新增 `soundEnabled` 设置（DataStore 键 `sound_enabled`，默认 true）。
✅ 设置页新增开关；`ReminderPrefs.shouldPlaySound` 纯函数判定（仅 high 且开启时发声/震动）。
✅ `ReminderReceiver` 高优先级提醒在开关关闭时不调用 `DEFAULT_SOUND/VIBRATE`，仅保留灯光与渠道重要性。
✅ 单测 `ReminderPrefsTest` 覆盖 `shouldPlaySound` 谓词。

### V2.32 折叠已完成任务
✅ 新增纯函数 `TodayListPrefs.shouldShowCollapseByDoneCount(count) = count > 20`（阈值常量 20）。
✅ `TodayScreen` 将列表拆分为「进行中 / 已完成」两段；已完成数 > 20 时默认折叠并显示「折叠/展开」开关。
✅ 已完成项保持下沉与半透明（复用 `TaskItem` 既有 done 样式）。
✅ 单测 `TodayListPrefsTest` 覆盖阈值判定。

### V2.33 组级暂停 / 启用 / 删除级联
✅ domain 层新增 `PauseTaskUseCase`/`ResumeTaskUseCase`（单任务 status ↔ PAUSED/ACTIVE）。
✅ `GroupUseCases` 新增 `PauseGroupUseCase`/`ResumeGroupUseCase`/`DeleteGroupCascadeUseCase`，级联作用于组内未软删子任务。
✅ `TasksViewModel` 新增 `pauseGroup`/`resumeGroup`/`deleteGroupCascade`，并在级联后取消/重排组内提醒与地理围栏。
✅ `TasksScreen` 组头新增「暂停/启用」切换按钮；删除确认文案更新为级联软删。
✅ 单测 `GroupUseCasesTest` 覆盖暂停/启用/删除级联落到子任务。

## 三、验收标准
- 单测：新增 `ReminderPrefsTest`(3) + `TodayListPrefsTest`(1) + `GroupUseCasesTest`(5)，全绿。
- `./gradlew :app:lintRelease` → 0 error（门禁 `abortOnError=true`）。
- 所有新增用户文案抽离至 `strings.xml`。

## 四、红线守住
- 零新依赖（仅复用既有 DataStore / NotificationCompat / Compose）。
- Room 无 schema 变更（本次未改实体/表）。
- 按功能拆分 commit：`[feature]` 设置与提醒偏好、`[feature]` 折叠已完成、`[feature]` 组级暂停级联、`[test]` 单测、`[docs]` 计划与发布说明。

## 五、已知限制（carry-over，非扣分）
- 离线热词 / 方言识别维持系统 best-effort（红线约束）。
- 单元测试覆盖率为纯逻辑模块（约 5% 指令级），UI/仓库/调度需 Robolectric 或仪器化测试，留待后续（引入 Robolectric 属新测试依赖，不在零依赖红线内）。

## 六、后续（v2.4+ 候选，非本版阻塞）
- 仪器化测试（Espresso/Compose UI test）覆盖折叠/组级暂停等交互，接 CI 模拟器真机化。
- 组级删除级联软删后，回收站恢复组时一并恢复其子任务（当前仅恢复组本身）。
- 离线 ML ASR 若未来解除红线，再做端侧推理接入。
