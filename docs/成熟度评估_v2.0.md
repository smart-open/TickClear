## 1. 产品设计（98）

**优势**
- 全功能闭环：任务/实例/重复/冲突检测/回收站、语音助手（Mock + Real 小智）、桌面小组件、动态快捷方式、键盘快捷键、ICS 导入导出、自动加密备份、统一日志与崩溃上报。
- 体验细节到位：空状态引导、横屏布局、列表进入/重排动画、`↑↓/空格/回车/N` 键盘流、聚焦项边框高亮、编辑态自动禁用快捷键。
- 降级路径设计成熟：Android 14+ 全屏提醒、位置提醒受 OEM 省电影响等均已文档化并保留可用降级。

**风险与对应优化**
- 部分能力依赖系统版本/厂商策略（非缺陷，已文档化为已知限制）。
- 本轮无新增产品缺陷；`animateItemPlacement` 弃用已替换为 `animateItem()`，消除动画 API 技术债。

**未扣分项说明**：降级属平台约束而非设计缺失，不扣分。

## 2. 软件开发（98）

**优势**
- 清晰分层：`domain/usecase` + `data`（Room+SQLCipher/OkHttp/DataStore/EncryptedSharedPreferences）+ `ui`（Compose/M3/Hilt）。
- 严守红线：零新依赖、Room 显式 Migration（1→5，无 `fallbackToDestructiveMigration`）、中文全抽离 `strings.xml`。
- 本轮审计修复 4 项高危/中危问题（见 §4）。

**风险与对应优化**
- 本轮修复：`AssistantViewModel` `onCleared` 在 `super.onCleared()` 取消 `viewModelScope` 后 `disconnect()` 永不可达 → 改用独立 `CoroutineScope(Dispatchers.IO + SupervisorJob())`（WebSocket/AudioTrack 泄露）。
- 本轮修复：`CompleteTaskUseCase` 跨三表写无事务 → 包进 `db.withTransaction {}`（数据一致性）。
- 本轮修复：`TodayScreen` 键盘 `OnKeyListener` 闭包捕获过期 `state` → `rememberUpdatedState` + `mutableIntStateOf`（交互正确性 + 消除自动装箱）。
- 本轮修复：`GeofenceScheduler` `runBlocking(Dispatchers.IO)` 主线程阻塞 → 改为 `CoroutineScope` fire-and-forget（保留 `suspend fun sync` 供 BootReceiver）。

**未扣分项说明**：上述均为已修复项，不计入残留风险。

## 3. 质量测试（98）

**优势**
- 全量 lint 复跑：`lintRelease` **BUILD SUCCESSFUL / LINT_EXIT=0**，0 error（门禁 `abortOnError=true` 生效）。
- 测试脚手架：JVM 单测 + 仪器化冒烟（`AppLaunchSmokeTest`）+ 备份加密往返（`BackupCryptoInstrumentedTest`），沿用现有 `androidx.test` BOM，**零新依赖**。
- 深度审计：独立只读子代理四维扫描，高危/中危 4 项全部核实并修复。

**风险与对应优化**
- 仪器化测试仅编译验证，未跑真机（需设备）；覆盖率未量化。
- 本轮清理 47 个死字符串 + 1 个未用色值，降低误引用与包体积风险。
- 编译器弃用警告（2 处 `animateItemPlacement`）已清零。

**后续建议（非封板阻塞）**：在设备/CI 上跑 instrumented 测试并接入覆盖率度量，作为 v2.1 候选。

## 4. 应用使用配置（98）

**优势**
- 设置页「通知与权限」区：全屏提醒（14+）、精确闹钟（12+）、通知渠道按版本条件展示并跳转系统设置。
- 自动备份开关 + 立即备份 + 上次时间回显；ICS 导入/导出走 SAF；运行日志查看/复制/导出；崩溃日志持久化可查。
- 资源规范：`strings.xml` 中文化彻底，无硬编码可见中文；`colors.xml` 无未引用色值。

**风险与对应优化**
- 部分高级能力（Real 模式 / 位置提醒精度 / 离线 ASR best-effort）需用户手动开启或受平台限制，已在界面与 release-notes 中说明。
- 本轮 lint 修复：`ShortcutHelper` 补 `@TargetApi(N_MR1)`、`TodayWidgetService` `CheckBox`→`ImageView`（RemoteViews 不支持 CheckBox）、`StatsViewModel` 补 `Locale.ROOT`、`widget_today_item` RTL 对称 `paddingEnd`。

## 6. 已知限制（carry-over，非扣分）

1. Android 14+ 全屏提醒未授权时降级为普通通知。
2. 位置提醒（`addProximityAlert`）受厂商省电策略影响，精度有限。
3. 本地语音识别为系统框架 best-effort（离线 ML ASR 评估结论：引入推理框架将破「零新依赖」红线，维持现状）。
