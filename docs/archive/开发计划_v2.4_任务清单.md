## 四、封板前代码审查加固（2026-07-25，四维 + 质量复查）

> 全量静态审查（独立只读子代理 + 人工核实）后，以最小代价修复以下真实问题，纳入 v2.4.0 封板：

### 红线回归修复（P0 · 中文未抽离）
- **离线指令动作回显**：`OfflineAction` 枚举 `label` 硬编码「暂停/启用/删除」→ 抽离到 `strings.xml`（`offline_action_pause/resume/delete`），`AssistantViewModel` 经 `when` 映射，源码零可见中文。
- **意图解析默认标题**：`TaskIntentParser` 兜底「新任务」→ 改由消费端 `MockXiaozhiTransport` 用 `task_default_title` 资源默认。
- **助手人设默认文案**：`SettingsRepository` 默认「你是用户的专属…」→ 抽离 `assistant_prompt_default`。
- **唤醒词默认短语**：`DEFAULT_WAKE_WORD = "小清"` → 抽离 `wake_word_default`，接口常量移除。
- **Mock 兜底日期**：`MockXiaozhiTransport` 兜底「今天」→ 抽离 `assistant_mock_when_today`。

### 资源 / 逻辑泄漏修复（P1）
- **`LocalSpeechRecognizer` 识别出错泄漏**：非连续模式 `onError` 仅复位 `running` 未 `destroy()`，旧 `SpeechRecognizer` 连接泄漏 → 改为调用 `stop()` 释放。
- **`WakeWordManager` 非局部返回**：`onFinal` 回调内 `return@start` 在 `start` 已返回后触发 `Already resumed` → 改为 `return`。
- **软删组级联恢复不对称**：`DeleteGroupCascadeUseCase` 级联前先 `detachFromGroup` 隔离组内「历史单独软删」任务，避免恢复组时经 `restoreByGroup` 一并复活（数据正确性）。`TaskDao/TaskRepository` 新增 `detachFromGroup`。
- **提醒误完成已删任务**：`ReminderReceiver.complete` 用 `getById` 兜底导致可完成已软删任务 → 仅用 `getActiveById`，软删任务通知应已取消。
- **离线指令 `Unknown` 空消息**：不可达分支会 `append("")` 触发无意义重组 → 改为 `return@launch`。
- **离线指令动作优先级**：文本同时含「删除+暂停」词时按 PAUSE 命中（误判）→ 改为 DELETE 优先。

### 测试加固
- `GroupUseCasesTest` 新增「级联删除组时历史软删任务脱离组、不重复软删」用例锁住对称修正。
