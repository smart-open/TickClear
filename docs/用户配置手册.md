# 点清 TickClear · 安装后配置手册

> 适用版本：v2.8.0（versionCode 16，2026-08-02 封板）。
> 本手册面向**最终用户**，讲解 App 安装后如何配置「设置功能 / 语音 ASR / 小智助手」。
> 技术实现细节见 [`docs/语音助手实现说明.md`](语音助手实现说明.md)（设计参考）与 [`docs/点清APP_产品设计文档.md`](点清APP_产品设计文档.md)。
> 更完整的测试与真机验收见 [`docs/测试与验收清单.md`](测试与验收清单.md)。

---

## 1. 安装与首次启动

- 安装：`adb install` 或 `./gradlew installDebug`（详见 [`docs/构建手册.md`](构建手册.md)），也可侧载 release APK。
- 首次启动会注入示例任务组与示例任务（仅一次，可随时在「今日 / 任务」删除）。
- **纯本地、无云端账号**：所有任务数据存于本机 SQLCipher 加密数据库，不上传任何服务器。

---

## 2. 必要权限（建议首次就授予）

| 权限 | 入口 | 作用 |
|---|---|---|
| 通知 | 设置 → 通知与权限 → 通知渠道 | Android 13+ 必须开启，否则收不到提醒 |
| 精确闹钟 | 设置 → 通知与权限 → 精确闹钟 | **Android 12 / 12L**：需手动授予 `SCHEDULE_EXACT_ALARM`，否则提醒降级为非精确（可能延迟数分钟）；**Android 13+**：App 已声明 `USE_EXACT_ALARM`（闹钟类应用），**安装即授予、无需手动操作** |
| 全屏提醒 | 设置 → 通知与权限 → 全屏意图 | Android 14+ 授予后重要提醒可全屏弹出；未授予降级普通通知 |
| 麦克风 | 助手页点麦克风 / 唤醒词时授权 | 语音输入与小智对话所需（RECORD_AUDIO） |

> 国产 ROM（小米 / 华为 / OPPO / vivo）还需在系统「自启动 / 电池白名单 / 后台弹出界面」中放行，否则后台提醒可能被杀。

---

## 3. 设置页功能详解

设置入口：底部「设置」Tab；平板（Medium/Expanded）为左导航轨的「设置」。分为左列（外观 / 提醒 / 助手）与右列（数据与隐私 / 通知与权限 / 关于 / 后续能力）。

### 3.1 外观
- **主题**：浅色 / 深色 / 动态（动态取色仅 Android 12+，低版本回退浅色）。
- **皮肤**：清蓝（默认）/ 薄荷 / 紫罗兰 / 落日橙 / 玫瑰 / 青碧，六套预设配色。皮肤与主题**正交**——最终配色 = 主题模式 × 皮肤（选「动态」时以系统取色为准）。
- **动画**：开关列表 / 卡片动画（低端机可关以提升流畅度）。

### 3.2 提醒
- **静音时段**：开启后默认 22:00–07:00 低优先级静默（不弹提醒音）。
- **稍后提醒默认时长**：5 / 15 / 30 分钟（提醒「稍后」按钮的取值）。
- **提醒音效**：关闭后「中」优先级提醒改为**静音但保留震动**；「低 / 静默」本就无声。**「高」优先级与习惯打卡提醒不受此开关约束，始终响铃 + 震动**（用户显式选「高」即表达「务必提醒到」的意图）。
- **清空前确认**：关闭后「一键清空今日」直接执行（无二次确认）。
- **离线语音指令**：开启后可用热词「暂停 / 启用 / 删除 + 任务名」直接操作任务，无需联网。

### 3.3 助手
- **助手模式**：`MOCK`（默认，离线模拟小智，无需服务端）/ `REAL`（连接真实小智服务端，见 §5）。
- **AI 引擎**：`LOCAL_NLU`（本地意图识别，当前唯一启用项；云端 LLM 在「后续能力」中置灰，配置见 §5）。
- **ASR 方言**：普通话 / 粤语 / 台湾 / 英语（调用**系统语音识别**语言包；设备需装有对应语音包，否则回退系统默认）。
- **语音历史**：默认**关闭**。开启后助手页的用户 / 助手文本会落本地加密库，并出现「查看语音历史」入口可浏览与清理；关闭时不落任何对话文本。

### 3.4 数据与隐私
- **回收站**：查看 / 恢复 / 彻底清理软删任务（默认 30 天自动彻底清理）。
- **导出 / 导入备份**：通过系统文件选择器（SAF）读写 JSON 明文备份（按主键合并导入）。
- **自动备份**：开关 +「立即备份」；每日加密备份到应用私有目录，并显示「最近备份时间」与「健康状态」（OK / 损坏 / 空 / 无）。
- **ICS 导入 / 导出**：与系统日历互导（.ics 文件）。
- **导出任务组模板**：选择一个任务组导出为 `type=groupTemplate` 的 JSON（含该组及其任务），在另一台设备用「导入备份」按主键合并即可成组复用。

> 备份 JSON 已包含习惯与打卡记录（`habits` / `habitCheckIns`），旧版本备份缺这两个数组也能正常导入（向后兼容）。

### 3.5 通知与权限
- 通知渠道 / 全屏意图 / 精确闹钟：点击跳转系统设置对应页面（按系统版本条件展示）。

### 3.6 关于 / 调试
- **关于**：版本号与版权信息。
- **调试**：运行日志查看 / 导出、测试通知、重排提醒（排查提醒不送达时使用）。

## 4. 语音与 ASR 使用

- 在「助手」页点麦克风按钮说话；首次会请求麦克风权限。
- 语音经 ASR 转为文字：**默认走「系统」识别**（设备内置，无需密钥）。需要更高精度可改为云端 ASR（见 §5.2）。
- **离线热词**：开启「离线语音指令」后，对麦克风说「暂停 XXX」「启用 XXX」「删除 XXX」（XXX 为任务名）可直接操作任务，不依赖网络。
- **语音建任务**：对话中说「提醒我明天 9 点开会」，助手解析为草稿卡片，确认后落库；开启「信任模式」可免确认（见 §5.4）。

## 5. 小智助手配置（助手配置面板）

进入「助手」页 → 点右上角齿轮（窄屏弹底部面板；宽屏常驻右侧面板）打开配置。

### 5.1 LLM 服务商（对话 / 人设后端）
- **小智（默认）**：选此项出现「助手模式 / 网关地址 / Token / 人设」：
  - 助手模式：`MOCK`（默认，离线演示）/ `REAL`。
  - 网关地址：默认 `wss://api.tenclass.net/xiaozhi/v1/`（官方真实域名，原 `api.xiaozhi.me/ws` 为错误地址已废弃），可改；激活设备后 OTA 返回的正确地址会自动填入并持久化。
  - Token：小智设备 6 位验证码绑定（个人非商用免费）。
  - 人设（prompt）：自定义 AI 风格 / 开场白，保存在 WebSocket 握手报文，全局生效。
- **OpenAI 兼容 / 豆包 / 千问**：填写 `baseUrl` / `API Key` / `model`。

### 5.2 ASR 服务商（语音识别后端）
- **小智**：由小智服务端识别，无额外配置。
- **系统**：设备内置识别，无需密钥（**推荐默认**）。
- **OpenAI 兼容**：`baseUrl` / `API Key` / `model`（如 `whisper-1`），可点「测试」验证连通。
- **腾讯云**：`SecretId` / `SecretKey`。
- **阿里云**：`AccessKeyId` / `AccessKeySecret` / `AppKey`。
- 选云端 ASR 后出现「测试连接」按钮，验证凭据可用后再保存。

### 5.3 语音唤醒词（离线）
- 开关 + 自定义词（默认「小清」）。开启后助手页出现唤醒按钮；说出唤醒词进入对话（依赖设备 ASR 能力，best-effort，非 Porcupine 等第三方引擎）。

### 5.4 信任模式
- 开启后，语音 / 对话解析出的任务草稿**免确认直接创建**（慎用，避免误建）。

## 6. 数据与备份（加密）

- 自动备份每日加密写入应用私有目录；「立即备份」手动触发；设置页显示最近时间与健康状态。
- 导出为 JSON（SAF）可异地保存；导入按主键合并（组 → 任务 → 完成记录 → 打卡 → 勋章），**整体在数据库事务中执行，中途异常自动回滚**，不留部分导入脏数据。仍建议导入前先做一次备份以防万一。
- ICS 与系统日历互导。
- ⚠️ **清除应用数据会丢失加密库**（口令存于 Keystore），需重新配置助手与备份。

---

## 7. 平台限制与排错

- Opus 编解码自 v2.8.0 起改用 App 内置 libopus 软件实现（不再依赖设备 `MediaCodec` 编码器，各机型均可用，含 arm64）；极少数机型原生库加载失败时自动降级文本模式（仍可对话，仅不传音频流）。
- Android 14+ 全屏提醒未授权时降级普通通知。
- 位置提醒（`addProximityAlert`）受厂商省电策略影响，精度有限。
- 国产 ROM 后台提醒需自启动 + 电池白名单。
- 离线 / 系统 ASR 为 best-effort；方言识别需设备装有对应语音包。
- 提醒送达率、Crash-free 等真机指标见 [`docs/测试与验收清单.md`](测试与验收清单.md) 第三节。

## 8. 语音不能用排查（V2.8X+ 诊断指引）

> 适用：助手 → 切到「REAL 模式」+ 端点配置好 + 设备已在 xiaozhi.me 控制台绑定，按下麦克风后 5+ 秒无 STT/LLM/TTS 回复；切到文本输入又能正常对话。

### 8.1 一分钟自查

按顺序检查：

1. **麦克风权限**：设置 → 通知与权限 → 麦克风（已授权）
2. **已绑定设备**：登录 https://xiaozhi.me → 「我的设备」能看到本机 MAC（Device-Id）
3. **Device-Id 大小写**：控制台绑定的 MAC 是**小写原样**（如 `e8:06:90:98:6c:d4`），App 端输入框也填小写
4. **文本能聊**：切到文本输入框发一句话，能正常回复说明握手/服务端没问题，问题只在上行链路

### 8.2 看 logcat 定位根因

```bash
adb logcat -c
adb logcat | grep -E "XzTransport|AudioCapture|OpusCodec|AssistantVM"
```

启动语音后，重点看这三条日志的**组合**：

| 看到的日志 | 根因分类 | 解决方向 |
|---|---|---|
| `AudioCapture` 有 "start OK" 但**无 `onFrame`**；线程退出时 `frameCount=0`、`readCount=0` | **B · read 阻塞** | 录音器启动但 read 一直未返回；检查是否被其他应用占用麦克风、关闭其他后台录音类应用；尝试重启手机 |
| `AudioCapture` 有 "start OK" 与 `onFrame`（录音正常），但**`OpusCodec` 持续 w 级 `encodeFrame 失败`** | **C · 编码失败** | v2.8.0 起已改用内置 libopus，正常不会再出现；若出现且报 `libsenz.so not found`，说明装的是 v2.8.0 之前的旧 APK，先 `adb uninstall com.tickclear.app` 再重装最新包；临时方案：用文本输入框 |
| `OpusCodec` 编码 OK（"encodeFrame OK 输出 NB"），但**`XzTransport.sendAudio` e 级错误** | **D · send 失败** | WebSocket 已断开但 sendAudio 还在被调用；正常退助手页后重新进入 |
| `AudioCapture` 标签只有 "start OK"、无 `onFrame`、`readZero>10` | **A · 录音未起** | 设备 `AudioSource.VOICE_RECOGNITION` 不可用；待 App 出方案 B（fallback MIC） |

### 8.3 仍连不通时

按 `XIAOZHI_DIAGNOSTIC_README.md` 的 §2-4 跑诊断脚本：
- `xiaozhi_diagnostic.py` 走纯标准库，验 App 协议字段是否对
- `mock_xiaozhi_server.py` 起本地 mock 服务端做端到端验证
- 若以上都通但官方云仍握手 1005，按 README §4「已知雷点」中的"测试连接一直 1005"处理（Device-Id 大小写 / license 不同步）
