## 五、已知限制（carry-over，非扣分）

1. **Opus 编码依赖设备能力**：Android `MediaCodec` 不保证提供 Opus 编码器（多数设备仅解码）；`encode` 失败返回 `null`，传输层自动降级文本模式。真实 Opus 编码需打包原生 `libopus`（增 NDK，按 best-effort 未引入）。
2. Android 14+ `setFullScreenIntent` 未授权时降级普通通知。
3. 位置提醒（`addProximityAlert`）受厂商省电策略影响，精度有限。
4. 本地语音识别为系统框架 best-effort（离线 ML ASR 会破「零新依赖」红线，维持现状）。
5. 仪器化 / Macrobenchmark 测试需在真机/CI 运行，当前仅编译验证。
