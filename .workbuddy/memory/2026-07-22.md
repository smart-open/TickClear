### 踩坑记录（重要）
- `strings.xml` 对同一 name 重复定义会 `mergeDebugResources FAILED: Found item String/xxx more than one time`；新增字符串前先 grep 全仓确认无同名（脚手架占位字符串易冲突）。
- Compose 内调用 composable 不能用 `forEach` lambda 间接包（除非函数是 inline 且在 composable 上下文被内联；`map`/`forEach` 的 lambda 类型非 `@Composable` 会报 "Composable invocations can only happen from the context of a @Composable function"）。`DropdownField` 的 `options.forEach{ DropdownMenuItem }` 能编译是因其位于 `ExposedDropdownMenu` 的 `@Composable` content lambda 内被内联；稳妥起见分组渲染用了 `for` 循环 / `LazyVerticalGrid.items`。
- `FilterChip(selected, onClick){...}` 尾随 lambda 会被错误解析到 `interactionSource` 参数 → 必须具名 `label = { ... }`。
- `by stateFlow.collectAsStateWithLifecycle()` 必须 `import androidx.compose.runtime.getValue`，否则 `State` 无法作委托、级联出 "Unresolved reference 'it'" 等怪异错误。
